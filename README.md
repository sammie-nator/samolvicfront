# Samolvic Technologies – Online Store

Premium cereals, foodstuffs & catering supplies.

## Tech Stack
- **Pure React** (Create React App – no Vite)
- Tailwind CSS
- No backend – everything runs client-side
- Orders & contact messages open WhatsApp directly

## Features
- Beautiful black & gold branded landing page
- Product catalog (cereals, pulses, essentials)
- Shopping cart with quantity controls
- One-click WhatsApp ordering
- Contact form → opens WhatsApp with pre-filled message
- Fully mobile responsive

## Quick Start

```bash
npm install
npm start
```

Open http://localhost:3000 in your browser.

To build for production:
```bash
npm run build
# Output is in the `build/` folder – can be hosted on any static host
```
